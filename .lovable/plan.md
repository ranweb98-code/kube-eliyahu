## שלב 5: חיבור נקודות רכישה ל-Google Sheets

### הגדרה:
1. יצירת Google Sheet עם עמודות: שם נקודה, עיר, כתובת, טלפון
2. קבלת **Google API Key** מה-Google Cloud Console (ללא צורך ב-OAuth)
3. שמירת ה-API Key כ-secret בפרויקט
4. יצירת **Supabase Edge Function** (`get-store-locations`) שקוראת מהגיליון דרך Google Sheets API
5. עדכון `StoreLocations.tsx` לשלוף נתונים מה-Edge Function במקום מהקוד הקשיח
6. שמירת cache קצר (5 דקות) כדי לא לעמוס על ה-API

### מה תצטרך לעשות:
- ליצור פרויקט ב-Google Cloud Console ולהפעיל את Google Sheets API
- ליצור API Key ולשלוח אותו כש-Lovable יבקש
- לשתף את ה-Sheet ID
